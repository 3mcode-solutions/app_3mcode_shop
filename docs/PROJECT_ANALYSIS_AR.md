## <a id="overview"></a>نظرة عامة

**3MCode Shop** هو تطبيق متجر إلكتروني متكامل مبني باستخدام إطار عمل Flutter، ويهدف إلى توفير تجربة تسوق سلسة للمستخدمين عبر منصات متعددة. يتميز التطبيق بواجهة مستخدم عصرية وسهلة الاستخدام، مع دعم كامل للغتين العربية والإنجليزية، ويوفر وضعي التصميم الفاتح والداكن.

### الإصدارات والتبعيات

- **Flutter**: الإصدار 3.19.3
- **Dart**: الإصدار 3.7.2
- **المنصات المدعومة**: Android، iOS، Web

## <a id="architecture"></a>الهيكل المعماري

يتبع المشروع نمط هندسة معمارية نظيفة (Clean Architecture) مع تطبيق مبدأ فصل المسؤوليات (Separation of Concerns). تم تصميم الهيكل المعماري للتطبيق بحيث يكون:

- **قابل للاختبار**: يمكن اختبار كل طبقة بشكل مستقل.
- **قابل للصيانة**: يمكن تعديل أي جزء من التطبيق دون التأثير على الأجزاء الأخرى.
- **قابل للتوسع**: يمكن إضافة ميزات جديدة بسهولة.
- **مستقل عن الإطار**: لا يعتمد على إطار عمل Flutter بشكل مباشر في طبقات المنطق والبيانات.

### الطبقات الرئيسية

يتكون التطبيق من ثلاث طبقات رئيسية:

#### 1. طبقة العرض (Presentation Layer)

تتضمن كل ما يتعلق بواجهة المستخدم وتفاعله مع التطبيق:

- **الشاشات (Screens)**: تمثل صفحات التطبيق المختلفة.
- **المكونات (Widgets)**: مكونات واجهة المستخدم القابلة لإعادة الاستخدام.
- **BLoCs**: مكونات إدارة حالة التطبيق التي تتوسط بين واجهة المستخدم والطبقات الأخرى.

#### 2. طبقة المنطق (Domain Layer)

تتضمن منطق الأعمال والقواعد الخاصة بالتطبيق:

- **حالات الاستخدام (Use Cases)**: تمثل العمليات التي يمكن للمستخدم القيام بها.
- **الكيانات (Entities)**: تمثل الكائنات الأساسية في التطبيق.
- **المستودعات المجردة (Repository Interfaces)**: تحدد العقود التي يجب أن تلتزم بها المستودعات.

#### 3. طبقة البيانات (Data Layer)

تتضمن كل ما يتعلق بالوصول إلى البيانات ومعالجتها:

- **المستودعات (Repositories)**: تنفيذ واجهات المستودعات المحددة في طبقة المنطق.
- **مصادر البيانات (Data Sources)**: تمثل مصادر البيانات المختلفة (محلية، بعيدة).
- **النماذج (Models)**: تمثل هياكل البيانات المستخدمة في التطبيق.

### هيكل المشروع

```
lib/
├── core/                   # المكونات الأساسية
│   ├── constants/          # الثوابت
│   ├── localization/       # التعريب والترجمة
│   ├── theme/              # سمات التطبيق
│   └── utils/              # أدوات مساعدة
├── data/                   # طبقة البيانات
│   ├── datasources/        # مصادر البيانات
│   ├── models/             # نماذج البيانات
│   ├── repositories/       # المستودعات
│   └── services/           # الخدمات
├── presentation/           # طبقة العرض
│   ├── blocs/              # مكونات إدارة الحالة (BLoC)
│   ├── screens/            # الشاشات
│   └── widgets/            # المكونات المرئية
├── app.dart                # تكوين التطبيق
└── main.dart               # نقطة الدخول للتطبيق
```

## <a id="features"></a>الميزات الرئيسية

### 1. واجهة المستخدم والتصميم

- **واجهة مستخدم عصرية**: تصميم عصري وجذاب يتبع أحدث اتجاهات التصميم.
- **وضع الظلام**: دعم كامل لوضع الظلام مع إمكانية التبديل بين الوضعين الفاتح والداكن.
- **تصميم متجاوب**: يعمل على مختلف أحجام الشاشات والأجهزة.
- **رسوم متحركة**: تأثيرات بصرية وانتقالات سلسة لتحسين تجربة المستخدم.

### 2. التعريب والترجمة

- **دعم اللغة العربية والإنجليزية**: واجهة مستخدم كاملة باللغتين.
- **تغيير اللغة**: إمكانية تغيير لغة التطبيق من الإعدادات.
- **دعم RTL**: دعم كامل لاتجاه النص من اليمين إلى اليسار للغة العربية.

### 3. المنتجات والتصنيفات

- **عرض المنتجات**: عرض المنتجات في تصنيفات مختلفة.
- **البحث والتصفية**: إمكانية البحث عن المنتجات وتصفيتها حسب معايير مختلفة.
- **تفاصيل المنتج**: عرض تفاصيل المنتج مع الصور والأسعار والتقييمات.
- **المفضلة**: إضافة المنتجات إلى المفضلة ومشاهدتها.
- **مشاركة المنتجات**: إمكانية مشاركة المنتجات مع الآخرين.

### 4. سلة التسوق والطلبات

- **سلة التسوق**: إضافة المنتجات إلى سلة التسوق وتعديل الكميات.
- **الدفع**: إتمام عملية الشراء مع خيارات دفع متعددة.
- **تتبع الطلبات**: عرض حالة الطلب وتتبعه على الخريطة.
- **سجل الطلبات**: عرض سجل الطلبات السابقة وتفاصيلها.

### 5. الحسابات والملفات الشخصية

- **تسجيل الدخول**: تسجيل الدخول وإنشاء حساب جديد.
- **الملف الشخصي**: تعديل معلومات الملف الشخصي.
- **العناوين**: إدارة عناوين الشحن.

## <a id="state-management"></a>إدارة الحالة

يستخدم التطبيق نمط BLoC (Business Logic Component) لإدارة حالة التطبيق، مما يوفر فصلاً واضحًا بين واجهة المستخدم ومنطق الأعمال.

### مكونات BLoC الرئيسية

1. **الأحداث (Events)**: تمثل الأحداث التي تحدث في التطبيق، مثل النقر على زر أو تحميل البيانات.
2. **الحالات (States)**: تمثل حالة التطبيق في لحظة معينة، مثل حالة التحميل أو الخطأ أو النجاح.
3. **BLoC**: يتلقى الأحداث ويعالجها وينتج حالات جديدة.

### أمثلة على BLoC في التطبيق

- **ProductBloc**: لإدارة حالة المنتجات (تحميل، بحث، تصفية).
- **CartBloc**: لإدارة حالة سلة التسوق (إضافة، إزالة، تعديل الكمية).
- **FavoriteBloc**: لإدارة حالة المفضلة (إضافة، إزالة).
- **LanguageBloc**: لإدارة حالة اللغة (تحميل، تغيير).
- **ThemeBloc**: لإدارة حالة السمة (تحميل، تغيير).
- **AuthBloc**: لإدارة حالة المصادقة (تسجيل الدخول، تسجيل الخروج).

## <a id="ui-ux"></a>واجهة المستخدم

### الشاشات الرئيسية

1. **الشاشة الرئيسية (HomeScreen)**: تعرض البانر المتحرك، التصنيفات، المنتجات الشائعة والجديدة.
2. **شاشة المنتجات (ProductsScreen)**: تعرض قائمة المنتجات مع خيارات البحث والتصفية.
3. **شاشة تفاصيل المنتج (ProductDetailScreen)**: تعرض تفاصيل المنتج مع خيارات الإضافة إلى السلة والمفضلة.
4. **شاشة سلة التسوق (CartScreen)**: تعرض المنتجات في السلة مع خيارات تعديل الكمية والإزالة.
5. **شاشة الدفع (CheckoutScreen)**: تتيح للمستخدم إدخال عنوان الشحن واختيار طريقة الدفع.
6. **شاشة تأكيد الطلب (OrderConfirmationScreen)**: تعرض تأكيد الطلب ورقم التتبع.
7. **شاشة المفضلة (FavoritesScreen)**: تعرض المنتجات المفضلة.
8. **شاشة البحث (SearchScreen)**: تتيح للمستخدم البحث عن المنتجات وتصفيتها.
9. **شاشة الإعدادات (SettingsScreen)**: تتيح للمستخدم تغيير إعدادات التطبيق مثل اللغة والسمة.

### المكونات المرئية

- **ProductCard**: بطاقة لعرض المنتج مع خيارات الإضافة إلى السلة والمفضلة.
- **CategoryItem**: عنصر لعرض التصنيف.
- **CartItemCard**: بطاقة لعرض عنصر في السلة مع خيارات تعديل الكمية والإزالة.
- **AnimatedButton**: زر متحرك للتفاعلات.
- **CustomAppBar**: شريط تطبيق مخصص.
- **LoadingIndicator**: مؤشر التحميل.
- **ErrorView**: عرض رسائل الخطأ.

## <a id="data-flow"></a>تدفق البيانات

### تدفق البيانات العام

```
واجهة المستخدم (UI) -> أحداث (Events) -> BLoC -> مستودعات (Repositories) -> مصادر البيانات (Data Sources) -> نماذج (Models)
```

### أمثلة على تدفق البيانات

#### 1. تحميل المنتجات

1. **واجهة المستخدم**: تعرض شاشة المنتجات.
2. **الحدث**: يتم إرسال حدث `LoadProducts` إلى `ProductBloc`.
3. **BLoC**: يتلقى `ProductBloc` الحدث ويطلب البيانات من `ProductRepository`.
4. **المستودع**: يجلب `ProductRepository` البيانات من `LocalData`.
5. **BLoC**: ينتج `ProductBloc` حالة `ProductLoaded` مع قائمة المنتجات.
6. **واجهة المستخدم**: تتحدث الشاشة لعرض المنتجات.

#### 2. إضافة منتج إلى سلة التسوق

1. **واجهة المستخدم**: يضغط المستخدم على زر "أضف إلى السلة".
2. **الحدث**: يتم إرسال حدث `AddToCart` إلى `CartBloc`.
3. **BLoC**: يتلقى `CartBloc` الحدث ويطلب إضافة المنتج من `CartRepository`.
4. **المستودع**: يضيف `CartRepository` المنتج إلى سلة التسوق في `LocalData`.
5. **BLoC**: ينتج `CartBloc` حالة `CartLoaded` مع قائمة المنتجات المحدثة.
6. **واجهة المستخدم**: تتحدث الشاشة لعرض رسالة تأكيد وتحديث عداد السلة.

## <a id="localization"></a>التعريب والترجمة

يستخدم التطبيق نظام ترجمة مرن يدعم اللغتين العربية والإنجليزية، مع إمكانية إضافة لغات أخرى بسهولة.

### آلية الترجمة

1. **ملفات الترجمة**: ملفات JSON تحتوي على ترجمات النصوص بلغات مختلفة.
2. **AppLocalizations**: فئة تتعامل مع تحميل وإدارة الترجمات.
3. **LanguageManager**: فئة تتعامل مع تخزين واسترجاع إعدادات اللغة.
4. **LanguageBloc**: يدير حالة اللغة في التطبيق.

### دعم RTL

يدعم التطبيق اتجاه النص من اليمين إلى اليسار (RTL) للغة العربية، مع مراعاة:

- استخدام خصائص مثل `start` و `end` بدلاً من `left` و `right`.
- استخدام `TextDirection` لتحديد اتجاه النص.
- عكس الأيقونات التي تشير إلى اتجاه مثل أسهم الرجوع والتقدم.

## <a id="future"></a>التطوير المستقبلي

### الميزات المخطط لها

1. **إكمال نظام الدفع والطلبات**:
   - تنفيذ صفحة الدفع مع خيارات متعددة
   - تنفيذ صفحة تأكيد الطلب
   - إضافة دعم الدفع عند الاستلام والدفع المحلي
   - تنفيذ صفحة تتبع الطلبات

2. **تحسين دعم اللغات**:
   - تحسين دعم اللغة العربية والإنجليزية
   - إضافة المزيد من النصوص المترجمة
   - تحسين دعم RTL في جميع أنحاء التطبيق

3. **تنفيذ وضع الظلام بشكل كامل**:
   - تحسين تجربة وضع الظلام
   - إضافة خيار التبديل التلقائي حسب إعدادات النظام
   - تحسين التباين والقراءة في وضع الظلام

4. **تحسين واجهة المستخدم وتجربة المستخدم**:
   - إضافة رسوم متحركة وتأثيرات بصرية
   - تحسين سرعة التحميل والاستجابة
   - تحسين تجربة المستخدم في الأجهزة المختلفة

### الرؤية المستقبلية

- **التوسع في المنصات**: تطوير نسخة ويب كاملة وتطبيقات سطح المكتب.
- **ميزات متقدمة**: إضافة الواقع المعزز (AR) والتعلم الآلي والذكاء الاصطناعي.
- **التكامل مع الأنظمة الأخرى**: التكامل مع أنظمة إدارة المخزون والمحاسبة وإدارة علاقات العملاء.
- **برنامج الولاء والمكافآت**: إضافة نقاط الولاء والكوبونات والخصومات والعروض الخاصة.
