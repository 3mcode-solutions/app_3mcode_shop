# توثيق ميزة الوضع الداكن (Dark Mode)

## نظرة عامة

ميزة الوضع الداكن تتيح للمستخدمين تغيير مظهر التطبيق من الوضع الفاتح (Light Mode) إلى الوضع الداكن (Dark Mode) لتحسين تجربة المستخدم، خاصة في الإضاءة المنخفضة وفي الليل. يساعد الوضع الداكن في تقليل إجهاد العين وتوفير طاقة البطارية في الأجهزة ذات شاشات OLED.

## المكونات الرئيسية

### 1. مدير السمات (ThemeManager)

يتحكم في تغيير سمة التطبيق وحفظ تفضيلات المستخدم:

- **getCurrentTheme**: يسترجع السمة الحالية (فاتح/داكن)
- **setTheme**: يغير السمة ويحفظ التفضيل
- **toggleTheme**: يبدل بين الوضعين الفاتح والداكن

### 2. كتلة السمات (ThemeBloc)

تدير حالة السمة في التطبيق باستخدام نمط BLoC:

- **ThemeState**: يمثل حالة السمة الحالية (فاتح/داكن)
- **ThemeEvent**: أحداث تغيير السمة
- **ThemeBloc**: يستجيب للأحداث ويحدث الحالة

### 3. ألوان التطبيق (AppColors)

مجموعة من الألوان المستخدمة في التطبيق، مع نسخ مختلفة للوضعين الفاتح والداكن:

- **primary**: اللون الرئيسي للتطبيق
- **background**: لون خلفية الشاشات
- **surface**: لون خلفية البطاقات والعناصر
- **text**: لون النصوص
- **textSecondary**: لون النصوص الثانوية
- **divider**: لون الفواصل

## كيفية عمل الوضع الداكن

### 1. تبديل الوضع الداكن

يمكن للمستخدم تبديل الوضع الداكن من خلال:

- **زر التبديل في شاشة الإعدادات**: يتيح التبديل اليدوي بين الوضعين
- **إعدادات النظام**: يمكن ضبط التطبيق ليتبع إعدادات النظام تلقائيًا

### 2. تطبيق السمة

عند تغيير الوضع، يحدث ما يلي:

1. يتم تحديث حالة `ThemeBloc`
2. يتم إعادة بناء شجرة الواجهة مع السمة الجديدة
3. يتم تطبيق ألوان مختلفة على جميع عناصر الواجهة
4. يتم حفظ تفضيل المستخدم في التخزين المحلي

### 3. تخصيص العناصر

جميع عناصر واجهة المستخدم تستجيب للتغيير في السمة:

- **البطاقات**: تتغير ألوان الخلفية والحدود
- **النصوص**: تتغير ألوان النصوص لضمان القراءة الجيدة
- **الأزرار**: تتغير ألوان الخلفية والنصوص
- **الأيقونات**: تتغير ألوان الأيقونات لتناسب السمة
- **الشاشات**: تتغير ألوان خلفية الشاشات

## مقارنة بين الوضعين الفاتح والداكن

| العنصر | الوضع الفاتح | الوضع الداكن |
|--------|-------------|-------------|
| خلفية التطبيق | أبيض (#FFFFFF) | أسود داكن (#121212) |
| خلفية البطاقات | أبيض فاتح (#F5F5F5) | رمادي داكن (#1E1E1E) |
| النصوص الرئيسية | أسود (#000000) | أبيض (#FFFFFF) |
| النصوص الثانوية | رمادي داكن (#757575) | رمادي فاتح (#BBBBBB) |
| اللون الرئيسي | أخضر (#4CAF50) | أخضر فاتح (#66BB6A) |
| الفواصل | رمادي فاتح (#EEEEEE) | رمادي داكن (#333333) |

### 2. تعريف الألوان

```dart
// في الوضع الفاتح
static const Color primary = Color(0xFF4CAF50);
static const Color background = Color(0xFFFFFFFF);
static const Color surface = Color(0xFFF5F5F5);
static const Color text = Color(0xFF000000);

// في الوضع الداكن
static const Color primaryDark = Color(0xFF66BB6A);
static const Color backgroundDark = Color(0xFF121212);
static const Color surfaceDark = Color(0xFF1E1E1E);
static const Color textDark = Color(0xFFFFFFFF);
```

### 3. تطبيق السمة

```dart
ThemeData getLightTheme() {
  return ThemeData(
    brightness: Brightness.light,
    primaryColor: AppColors.primary,
    scaffoldBackgroundColor: AppColors.background,
    // ... المزيد من الإعدادات
  );
}

ThemeData getDarkTheme() {
  return ThemeData(
    brightness: Brightness.dark,
    primaryColor: AppColors.primaryDark,
    scaffoldBackgroundColor: AppColors.backgroundDark,
    // ... المزيد من الإعدادات
  );
}
```

## تحسينات الأداء

### 1. تقليل استهلاك البطارية

الوضع الداكن يساعد في تقليل استهلاك البطارية بنسبة تصل إلى 30% في الأجهزة ذات شاشات OLED، حيث أن البكسلات السوداء لا تستهلك طاقة.

### 2. تحسين الأداء البصري

- **تقليل إجهاد العين**: خاصة في الإضاءة المنخفضة وفي الليل
- **تحسين التباين**: يوفر تباينًا أفضل للنصوص والعناصر
- **تقليل الوهج**: يقلل من الوهج المنبعث من الشاشة

## تجربة المستخدم

### 1. التبديل السلس

- تم تنفيذ انتقال سلس بين الوضعين باستخدام رسوم متحركة
- يتم تطبيق التغييرات فورًا دون الحاجة لإعادة تشغيل التطبيق

### 2. الاتساق

- جميع شاشات التطبيق تدعم الوضع الداكن بشكل كامل
- تم تصميم جميع العناصر لتعمل بشكل جيد في كلا الوضعين

### 3. الخيارات

- يمكن للمستخدم اختيار الوضع المفضل (فاتح/داكن)
- يمكن ضبط التطبيق ليتبع إعدادات النظام تلقائيًا

## التحسينات المستقبلية

1. **سمات إضافية**: إضافة سمات ملونة متعددة إلى جانب الوضعين الفاتح والداكن
2. **جدولة السمات**: تغيير السمة تلقائيًا حسب الوقت من اليوم
3. **تخصيص أكثر**: السماح للمستخدم بتخصيص ألوان معينة في السمة
4. **وضع القراءة**: إضافة وضع خاص للقراءة يقلل من الضوء الأزرق

## الاختبار

تم اختبار ميزة الوضع الداكن على:
- أجهزة مختلفة (هواتف وأجهزة لوحية)
- إصدارات مختلفة من نظام التشغيل
- أحجام شاشات مختلفة
- ظروف إضاءة مختلفة

## الخلاصة

ميزة الوضع الداكن تحسن بشكل كبير تجربة المستخدم وتوفر راحة أكبر للعين، خاصة في الإضاءة المنخفضة. كما أنها تساعد في توفير طاقة البطارية في الأجهزة ذات شاشات OLED. التنفيذ الحالي يوفر تجربة سلسة ومتسقة عبر جميع أجزاء التطبيق.
